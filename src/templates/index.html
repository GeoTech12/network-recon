Authorization & Ethical Use

Network Recon is intended only for networks you own or have explicit written permission to assess. Do not use it against arbitrary Internet targets. The tool does not attempt authentication, exploit vulnerabilities, or perform denial-of-service testing.

Run a Scan

Discovery sends a single ICMP echo request to each address on your local private subnet. MAC addresses are read from this machine's existing ARP cache; hostnames are looked up only when reverse-DNS resolution is enabled. When TCP port checks are enabled, a fixed list of seven common ports (21, 22, 53, 80, 443, 445, 3389) is tested with a plain connect attempt — no banners, no UDP. Port checks are off by default. Missing hostnames, MAC addresses and open ports are all normal.
